# المقارِن الفقهي المالكي (ي ع ش خ س)

موقع تفاعلي يعرض في كل باب ما قاله خمسة متون مالكية، جنبًا إلى جنب، بنصوصها الأصلية مع رابط المصدر لكل فقرة:

| الرمز | المتن | المصدر الرقمي |
|---|---|---|
| ي | مختصر الأخضري | المكتبة الشاملة، كتاب 9548 |
| ع | المرشد المعين (ابن عاشر) | دروس محظرية ma7dhara.com + مقابلة على «الدر الثمين» لميارة (الشاملة 14249) |
| ش | أسهل المسالك (محمد البشار) | الشاملة 631 (مجموع الرفعة) |
| خ | مختصر خليل | متن «تحبير المختصر» لبهرام، الشاملة 147313 |
| س | الرسالة (ابن أبي زيد) | نسخة التتائي، الشاملة 1430 |

- البيانات كلها في `data/fiqh.json`، وتُبنى آليًا بـ `tools/build_data.py` من صفحات المصادر (لا يُكتب أي نص يدويًا).
- لإضافة باب أو متن: أضِف عنصرًا في `chapters` أو `texts` بنفس البنية.
