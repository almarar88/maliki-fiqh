# المقارِن الفقهي المالكي v2 (ي ع ش خ س)

موقع تفاعلي يعرض ٢٩ بابًا من أبواب العبادات (الطهارة، الصلاة، الزكاة، الصيام والاعتكاف، الحج) في خمسة متون مالكية جنبًا إلى جنب، بنصوصها الأصلية مع رابط المصدر لكل فقرة.

| الرمز | المتن | المصدر الرقمي |
|---|---|---|
| ي | مختصر الأخضري | المكتبة الشاملة، كتاب 9548 |
| ع | المرشد المعين (ابن عاشر) | المتن الكامل من tariqa-tijaniyya.es، مقابَل بيتًا بيتًا على «الدر الثمين» لميارة (الشاملة 14249) وعلى ma7dhara.com |
| ش | أسهل المسالك (محمد البشار) | الشاملة 631 |
| خ | مختصر خليل | متن «تحبير المختصر» لبهرام، الشاملة 147313 |
| س | الرسالة (ابن أبي زيد) | نسخة التتائي، الشاملة 1430 |

- البيانات في `data/fiqh.json` وتُبنى آليًا بـ `tools/build_data.py` (لا نص مكتوب يدويًا).
- الواجهة: HTML/CSS/JS بلا مكتبات؛ خريطة أبواب، وضع مقارنة الألفاظ، وضع حفظ، استماع (Web Speech)، مراجعة بنقاط ومراتب وأهداف يومية، صانع رسالة.
- المساعد ✦: `worker/worker.js` (Cloudflare Worker + Workers AI، بلا مفاتيح في الواجهة، محدود المعدّل). يسترجع من نصوص الموقع فقط ويذكر المصادر. الموقع يعمل كاملًا بدونه.
- تعليمي للمراجعة، ليس فتوى. للفتوى في الإمارات: 800 22 24.
